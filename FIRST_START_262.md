# 2.62 — первый запуск и доступ к профилю

После чистой установки приложение автоматически запрашивает системное разрешение READ_PHONE_STATE (диалог Android группы «Телефон»). После его выдачи, если служба Shizuku запущена, последовательно открывается её запрос доступа. Одновременно два запроса не запускаются. Автоматический запрос каждого разрешения выполняется один раз; после отказа остаются ручные кнопки. Если Shizuku не запущена, её первое подключение запускает запрос после возвращения в приложение. Уже выданные разрешения повторно не запрашиваются. Профиль автоматически не применяется.

Если SIM определилась, но доступа Shizuku нет, на карточке оператора вместо неактивной кнопки применения отображается «Предоставить доступ к Shizuku». После разрешения пользователь сам нажимает «Применить профиль» и подтверждает действие. Проверка настроек (Check) ничего не записывает.

Исправлен ошибочный текст «Подписка изменилась» при отсутствии разрешения на чтение SIM. Теперь экран объясняет необходимость доступа.

В предоставленном SIM (4).txt есть только PHONE_PERMISSION_RESULT и PROFILE_CHECK: DIFFERENT. Запуск применения отсутствует (REGION_NOT_STARTED), APN_NOT_CHECKED. Причина сетевого отказа в этом журнале не зафиксирована. На скриншотах Shizuku не авторизована.

Все четыре PB-профиля и механизмы записи/APN сохранены без изменения.
