# 2.64 — МегаФон Россия v2, экспериментальный ePDG

Для SIM 25002 добавлены два параметра:

```ini
iwlan.epdg_static_address_string = "epdg.epc.mnc002.mcc250.pub.3gppnetwork.org"
iwlan.epdg_address_priority_int_array = [0, 1]
```

Адрес взят из модемного профиля Xiaomi MegaFon. Приоритет соответствует примерам telekom_de.pb и tmobile_us.pb в исследованном наборе Pixel CarrierSettings. 0 — статический адрес, 1 — определение по PLMN. Это кандидат для испытаний на Pixel, а не подтверждение работающего VoWiFi.

В подробностях профиля показаны адрес и порядок выбора ePDG. Проверка активации сравнивает как строку адреса, так и упорядоченный массив приоритетов. Типизированный массив записывается в CarrierConfig как IntArray; при чтении приводится к списку для сравнения содержимого. PB-профиль закреплён контрольной суммой, его ограниченный декодер принимает только утверждённые [0,1]. Старый режим megafon_ru_v1 остаётся читаемым в истории, но повторно не отправляется.

APN, UT/XCAP hos, SMS, USSD и остальные настройки МегаФона не менялись. Отдельный адрес ePDG для роуминга, IKE/IPsec, аутентификация, entitlement и таймеры не переопределяются. Четыре других PB-профиля сохранены без изменения.

После установки новой версии профиль МегаФона нужно применить повторно. CarrierConfig временный, до перезагрузки; сама установка APK профиль не активирует. Проверка на сети и устройстве не проводилась.
