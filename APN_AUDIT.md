# APN implementation audit

New files: IApnBridge.aidl, ApnBridgeService.kt, ApnSession.kt, ApnRules.kt, ApnCodec.kt; JVM tests ApnChecks.kt.

Existing CarrierTrialService, RegionSession, ICarrierTrial and read-only/number backends are unchanged. MainActivity only initializes the APN pending-operation guard. APN writes are not added to IReadOnlyBridge.

Only command forms generated by the helper, with ProcessBuilder argument lists and no sh -c/string interpolation:
- /system/bin/content query --uri content://telephony/carriers/preferapn/subId/INTEGER --projection FIXED_COLUMNS --user APP_USER
- same read of carriers/sim_apn_list/filtered/subId/INTEGER
- /system/bin/content update --uri content://telephony/carriers/preferapn/subId/INTEGER --bind apn_id:l:NONNEGATIVE_LONG --user APP_USER

The helper exposes no arbitrary URI, shell, selection, ContentValues, package or command argument. Caller UID must match the app; mapping is verified via ISub. Query output is capped, parsed strictly in a fixed projection order, and rejects unexpected lines, duplicate IDs or malformed fields. Queries are bounded; update timeout retains the process and an unknown outcome, without destroying/repeating a possible write. Tokens are single-use and expire after 120 seconds.

AOSP references checked 2026-10-23:
- https://android.googlesource.com/platform/packages/providers/TelephonyProvider/+/refs/heads/main/src/com/android/providers/telephony/TelephonyProvider.java — URL_PREFERAPN_USING_SUBID update sets preferred apn_id for the explicit subscription, not the carriers record.
- https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/cmds/content/src/com/android/commands/content/Content.java — content CLI argument lists, --user and long bindings.

No provider restore/default reset, APN insert/delete, radio reset or boot receiver. No IMS phone numbers in this feature. Snapshot is private metadata, not a complete APN backup.
