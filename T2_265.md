# T2 Россия v1 — экспериментальный профиль

Привязка источника и назначения: 25020 → 25020. Carrier ID APN: 1028. На Pixel и в сети T2 не проверен. Добавлены карточка оператора, значок T2, подробности, применение и проверка активации. Все пять предыдущих PB-профилей сохранены, включая МегаФон v2 с ePDG. Первый запуск из 2.62 сохранён.

| APN | Тип | Протокол дома / роуминг |
|---|---|---|
| internet | default | IPv4/IPv6 / IPv4/IPv6 |
| mms | mms | IPv4 / IPv4 |
| ims | ims | IPv4/IPv6 / IPv4/IPv6 |
| hos | xcap | IPv4/IPv6 / IPv4/IPv6 |

Логин и пароль не заданы. APN-аутентификация оставлена неопределённой (-1), как в Xiaomi product. IMS и XCAP скрыты. MMS: http://mms, прокси 193.12.40.65:8080.

Флаги: VoLTE, VoWiFi, видеозвонки, UT/XCAP и SMS через IMS разрешены; USSD предпочитает IMS с переходом в CS; отображение 4G/4G+ разрешено. Эти флаги не подтверждают работу услуг.

Сервер XCAP: xcap.ims.mnc020.mcc250.pub.3gppnetwork.org:80. Совпадает с Samsung TELE2_RU и Xiaomi Tele2 MBN; порт 80 явно найден в Xiaomi и совпадает с базовым значением Samsung.

BSF выбран из Samsung: bsf.ims.mnc020.mcc250.pub.3gppnetwork.org:80. Порт 80 наследуется из общих настроек Samsung. У Xiaomi отличается имя: bsf.mnc020.mcc250.pub.3gppnetwork.org:80 (без ims). Второй адрес сохранён как альтернатива для отдельной диагностики, не смешивается с первым.

Samsung TELE2_RU: enableIms/enableServiceVolte/enableServiceVowifi/enableServiceVilte/enableServiceSmsip=true; IMS содержит mmtel, mmtel-video, smsip; support_3gpp_ussi=true; ussd_domain_setting=PSCS; ss_domain_setting=PS_ONLY_VOLTEREGIED. В активном блоке Xiaomi 25020 явно включены VoLTE, VoWiFi и VT.

APN взяты из Samsung SER T2: internet/mms/ims/hos. Xiaomi product подтверждает первые три коротких APN и MMSC/прокси. Xiaomi system содержит другой набор: internet.tele2.ru, mms.tele2.ru, ims.tele2.ru, hos.tele2.ru, MMSC http://mmsc.tele2.ru. Выбран единый набор Samsung. Samsung MMS содержит HTTP Auth=normal без учётных данных; Xiaomi APN authtype не задаёт. MVNO-записи Ростелекома/Сбера не переносились.

Xiaomi Tele2 MBN: static_fqdn_enabled=FALSE; статический адрес ePDG не найден. Для T2 параметры статического ePDG и приоритета не переопределены. Голосовая почта, NR/диапазоны, модемные NV, таймеры и криптография оставлены системными.

CarrierConfig временный, до перезагрузки; APN сохраняются. Старые APN не удаляются и конфликтующие записи не переписываются. Проверки привязки выполняются по MCC/MNC 25020, поэтому это не отдельный фильтр всех MVNO, использующих тот же MCC/MNC.

Источники: Samsung A576B TELE2_RU globalsettings/imsswitch/imsprofile и SER customer.xml; Xiaomi OS3.0.308.0.WPARUXM APN, MiuiCarrierConfigOverlay default_v2.9.7.xml и Tele2 MBN. Извлечённые блоки Samsung: outputs/Samsung-T2-RU.
