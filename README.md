# Pixel Carrier Profiles

Android-приложение для применения профилей своего оператора через Shizuku и просмотра состояния IMS.

Профили привязаны к MCC/MNC SIM. Доступны A1 BY, MTS BY, MTS Russia, Beeline, Megafon и T2. Российские профили экспериментальные. Для A1 проверялись VoLTE и UT на одном устройстве. Доступность услуг зависит от сети и устройства.

В профиле A1 VoWiFi выключен по умолчанию. Поддержка VoWiFi сохранена для ручного включения в настройках телефона. Уже сохранённый пользовательский выбор Android может иметь приоритет над значением по умолчанию.

## Сборка

Требуются JDK 17 или 21, Android SDK 35 и Gradle 8.9. Укажите путь SDK через ANDROID_HOME или local.properties.

    .\gradlew.bat :app:assembleDebug :app:lintDebug :app:coreChecks

Ключ подписи хранится отдельно. Для обновления ранее установленной версии используйте тот же ключ подписи.

Идентификатор Android-пакета сохранён для совместимости обновлений. Подготовленные исходники основаны на версии 2.65. Изменения названия и VoWiFi пока не выпущены отдельным APK.

Профили расположены в profiles/, встроенные PB-файлы — в app/src/main/assets/. Проверка LocalPbRules должна соответствовать содержимому профилей.

Сторонние компоненты перечислены в THIRD_PARTY_NOTICES.txt.

## Проверка подготовленных исходников

Проверены XML-ресурсы, структура всех шести профилей, совпадение встроенных PB-файлов и контрольная сумма A1. Полная сборка в текущем окружении остановилась при разрешении Android Gradle Plugin 8.7.3. Успешная сборка этих изменений пока не подтверждена.
